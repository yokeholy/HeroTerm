## Reshooting

- Use a throwaway `HOME` with a plain prompt, so no username, hostname or real
  paths end up in a public image — and so the test shells can't touch your own
  shell history.
- Set *Unfocused window opacity* to about 60% first; at the default 20% the
  other windows barely show.
- The vanishing point sits at the centre of whatever is running, so a window in
  the dead centre of the page hides the convergence. Off-centre, or wide enough
  that it clears the frame, reads best.
