HeroTerm

Your real shell, in a browser tab.

Each command gets a window

The screen clears for every command, and the one before it stacks up behind. The border says how it went: yellow running, green clean, red failed.

Workspaces

left edge
rest the pointer on the left edge: the panel that slides out holds your workspaces, each with its own windows and shells. Switching hides one set and shows another — nothing restarts, and a build left running in another workspace keeps going

Save this workspace…, at the bottom of the panel, keeps its windows, where they sit and the folder each shell was in — and each window's commands, which keep themselves from then on. Saved ones are listed under it; opening one gives it a workspace of its own, every window with its earlier commands on the deck and on ↑. Save on its row updates the layout

Settings

The text in every terminal. ⌘+ and ⌘− still size one window for a while; ⌘0 comes back to this.

px

Everything else with words on it: title bars, the status bar, buttons, and these sheets. Each sample is shown at the size it gives you.

How much of a window you are not working in is left on screen. Lower values let the star field through; the window you're typing into is always solid.

%

All of them at once. Each can also be turned off on its own below — turning one on plays it, so you know which it is.

How loud all of them are. Moving this plays one, so you can hear where you have put it.

%

The rush outward while a command runs, from the middle of whatever is working. Off leaves the sky where it is, still breathing; turning it on shows you for two seconds.

Letting go of a selection puts it on the clipboard, the way iTerm does. ⌘C works either way.

When the red button should ask first. "While running" asks only if a command hasn't finished — a build, an ssh session, Claude Code. A shell that exits by itself never asks.

Commands to neither hear nor watch — a dev server, a log you're tailing, anything that runs all day. One a line; a command containing any of them makes no sound and doesn't fly the stars. It still gets its window, its clock and its border.

How long a shell waits to be reattached — a refresh, a reopened tab, a laptop coming back from sleep. Whatever was running keeps running for that long. "Server default" leaves it to whoever started HeroTerm (HEROTERM_GRACE, 10 minutes if unset).

Asks the npm registry, every few hours, for HeroTerm's latest version. Updating is always your call.

What HeroTerm is running with. Read-only here: each says where it's set. Server values take effect when the server restarts; the page's, when you reload.

Colour only — the typeface, spacing and timings are the same whichever you pick, so switching can never hand you a font you didn't ask for.

The fonts installed on this machine that this browser can draw. A terminal draws on a grid, so only monospaced ones are listed unless you ask; anything the one you pick is missing — prompt icons, say — still comes from the default.
